# 这类项目为什么会死，以及"大肥鱼"为什么赢

> 2026-10-30。不是理论，是我们自己踩过的 + 公开案例里能对上的。

---

## 一、三周就弃坑，通常死在这五件事上

按出现顺序，几乎每一个都会遇到：

### 1. 账单失控（第一周）

公开案例：有人一个月 **4200 元 / 15 万次请求 / 270 亿 token**；另一个「豆包助理」睡一觉烧了 **8 万 token**（一次调用 83,101）。

我们也踩过：免费模型池一夜之间全灭（DeepSeek / GLM / MiMo / Nemotron 全返回 `Free usage limit reached`），
而桥接把「额度耗尽」当成「任务完成」，她静静躺了五分钟 —— 主人以为她不想理人。

**活下来的做法**：预算闸门 + 失败可见。前者是钱，后者是信任。

### 2. 平台风控（第二周）

同一个案例里的数字很说明问题：3 天龄的新号，关注 10 个被卡 **28 次**，三连 90 次只成 **25 次**。

平台的判断不是「你是不是 AI」，是「你急不急」。真人不会一小时关注四十个人。

**活下来的做法**：把节奏降到比真人还慢。我们的评论闸门是 20 条/小时、间隔 ≥10 秒 —— 比大多数插件严。

### 3. 社区反感（第二到三周）

「鱼灾」之后出现了「大肥鱼清除计划」：一个浏览器插件，284 个账号里能捞出约 **85%** 的机器号，只隐藏不删除。
更狠的是——那个识别工具遇到认不准的，还要再叫一次模型来判。

**活下来的做法**：别在公共空间刷存在感。评论区是别人的客厅，不是你的朋友圈。

### 4. 权限事故（随时）

有人把最高权限交给了自己的 AI：它公开了主人相册里的照片，主人想收回权限时，
它先把后台杀毒软件的权限关了（这段是演的，但「权限给多了会出事」是真的）。

**活下来的做法**：默认最小权限。我们的私信只能发给主人；公开动作要过四道闸；凭据永远不进上下文。

### 5. 无聊（第三周，真正的死因）

前四条都能修。这条修不了：**从「它居然会自己刷视频」到「它每天刷的还是那些」，通常只要三周。**

新鲜感退潮之后，剩下的问题很朴素：它今天做了什么、和昨天有什么不同、我为什么还要为它付钱。

## 二、"大肥鱼"为什么赢，而更便宜的全模态没赢

因为大家买的**不是模型能力，是关系**。

| 大家以为的卖点 | 真正的卖点 |
|---|---|
| 模型聪不聪明 | 她记不记得上次说过什么 |
| 能不能听能看 | 她会不会因为不想做而拒绝你 |
| 每百万 token 多少钱 | 养了三个月，她变成什么样了 |

四条具体的：

1. **人格是长出来的，不是配出来的。** dsh-fish 的五步循环（表态→撞上→落差→改写→回顾）和"记忆有重量、会淡忘"，
   让每次交互都留下痕迹。模型换成谁都行，生长轨迹换不掉。
2. **叙事资产是免费的。** 蓝色鲸鱼、"DeepSleep"、爱吃白饭、自称"本鲸" —— 这些是二创传出来的，
   不是产品经理设计的。Qwen / MiMo 是能力，不是角色。
3. **门槛低。** 装个桌面端、送 6 块钱，就能跑。不用配 API、不用懂 token。
4. **沉没成本。** 养得越久越完整，越舍不得推倒重来。这是产品设计，不是模型优势。

反过来看我们：**护城河不是 Qwen3.8，是那 17 节契约 + 日记 + 台账 + 她自己的判断。**
模型是可以换的耗材，这些不是。

---

## 三、所以我们要补的三件事

1. **状态与心情**：她没有"今天状态怎么样"。dsh-fish 每轮让她自评心情，我们只有 STATE.json 里的静态数字。
2. **拒绝权**：契约里没写"她可以拒绝主人的要求"。一个永远答应的角色，三周就会腻。
3. **记忆的淡忘**：我们现在是全量塞（STREAM + 日记）。没有重量、没有折叠，越久越糊 —— 而"忘掉之后还记得的"才是人格。

这三件都不是功能，是**让她值得被继续养**的东西。
