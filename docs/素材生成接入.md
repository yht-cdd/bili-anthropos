# 素材生成：接一个能出图 / 出片的 API

> **本仓库不指定、也不推荐任何供应商。**
> 你需要自己选一家（或自建），把地址填进配置。我们只提供适配层。

---

## 1. 为什么需要外部 API

Remotion（见 [视频管线](视频管线.md)）只能做**合成**：文字、图形、转场、音轨。
它画不出「一只猫在雨里走路」这种画面 —— 那要生成模型。

所以渲染这条线有两个来源：

```
文字/图形/排版     →  Remotion 自己画（免费、可控、4C16G 就能跑）
真实感画面/B-roll  →  外部生成 API（花钱、慢、但只有它能画）
```

## 2. 怎么接

```bash
cp config/media-api.example.json config/media-api.json
# 填 baseUrl / 模型名 / 路径；key 放到 secrets/media_api_key.txt（600）
node scripts/gen-media.mjs models                 # 确认能连上
node scripts/gen-media.mjs image --prompt "…"     # 出图
node scripts/gen-media.mjs video --prompt "…"     # 出片
node scripts/gen-media.mjs usage                  # 今天花了多少次
```

配置项全部在这个文件里，**换供应商不用改代码**（除非对方接口形状特殊，见第 4 节）。

## 3. 脚本对接口做的假设

默认按 OpenAI 风格写，绝大多数服务都能对上：

| 动作 | 默认 | 可配 |
|---|---|---|
| 列模型 | `GET {baseUrl}/v1/models` | `modelsPath` |
| 出图 | `POST {image.path}`，body `{model, prompt, size}` | `image.path` / `image.model` / `image.extraBody` |
| 出片 | `POST {video.path}`，body `{model, prompt, mode}` | `video.path` / `video.modeField` / `video.modes` |
| 查任务 | 依次试 `video.statusPaths` 里的路径，`{id}` 占位 | `video.statusPaths` |

取结果时按常见几种形状兜：`data[0].url`、`data.url`、`data.video_url`、`data.output`。

## 4. 换供应商要改哪里

| 情况 | 改法 |
|---|---|
| 只是地址/模型名不同 | 改 `config/media-api.json`，不改代码 |
| 视频请求体字段不一样（有人要 `duration`，有人要 `num_frames`） | 改 `scripts/gen-media.mjs` 里的 `buildVideoBody()` —— **只有这一个函数** |
| 返回结构完全不一样 | 改 `pickUrl()` / `pickId()` / `pickStatus()` 三个小函数 |
| 要图生图 / 参考图 | 现在没实现，在 `genImage()` 的 body 里加字段即可 |

## 5. 通用的坑（跟供应商无关）

1. **视频基本都是「提交任务 + 轮询」**，不是同步返回。别指望一次请求拿到 mp4。
2. **队列满很常见**（429 / 503）。脚本会明确告诉你「不是你的事，过会儿再试」，不要在里面死循环重试 —— 那是白烧额度。
3. **尺寸常有枚举限制**。传一个「合理但不在白名单」的尺寸会 400，而且报错未必说清是尺寸问题。
4. **时长字段各家叫法不同**：`duration` / `num_frames` / `seconds`。写错会被当「禁止字段」拒掉。
5. **返回可能是 URL 也可能是 base64**，而且 base64 字段可能是个空字符串占位 —— 先看有没有 url。

## 6. 花钱的闸门

生成是付费动作，所以脚本自带三道：

1. **每日上限**（`dailyMax`，默认 10 次），到顶拒绝，`--force` 才能突破
2. **记账**：每次写 `bili/data/gen_usage.jsonl`（模型、提示词、字节、耗时）
3. **`usage` 子命令**：一眼看今天生成了什么

## 7. 还没做

- **图生图 / 参考图**：没接
- **视频任务查询**：路径写成了可配置的一串，但没有在真实任务上跑通过（对方队列一直是满的）
- **TTS（配音）**：生成 API 通常只管画面。配音要单独接一个语音合成，Remotion 那条线现在是无声的
- **EXA 之类的搜索 API**：仓库里没有接，需要自己加
