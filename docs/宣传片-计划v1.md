## 一、先想清楚：我们和它差在哪

看完那条参考片，它的叙事是：

> 我做了一个工具 → 一句话让 AI 学会运营 B 站 → 这条视频就是它自己投的

**它的主角是工具，AI 是工具的执行者。** 卖点是「安装门槛低」。

我们能讲的是完全不同的一件事：

| | bili-cli | 我们 |
|---|---|---|
| 形态 | 命令行工具 / skill | **一个常驻的运行主体** |
| 谁来驱动 | 人每次下令 | **她自己决定什么时候动** |
| 边界 | 默认限流、审计、风控即停 | 同上，**但她还会判断「这条值不值得回」** |
| 最狠的一句 | 「这条视频就是她自己投的」 | 「**从选题到投稿，中间没有人**」 |

所以整条片子只讲一句话：

> **别人给你一把工具，我们造了一个会上班的同事。**

而且必须把「会上班」拍实 —— 3 秒钟能说清的东西，要用具体动作证明，不能靠形容词。

## 二、片子骨架（75 秒，竖屏 1080×1920 / 30fps）

对标参考片的长度。全部无口播也能看懂（字幕 + 音效），配音可选。

| 时间 | 画面 | 字幕 / 落点 | 为什么这么设计 |
|---|---|---|---|
| **0–4s** | 纯黑。只有终端的打字光标在闪，一行字被一个字一个字敲出来 | `这条视频，没有人碰过键盘。` | 冷开场，先把结论扔出来制造疑问 |
| **4–11s** | 左右分屏：左边是常见的「AI 工具」面板（一堆参数滑条），右边是一片漆黑里只浮着一个名字 | `别人做的是工具。`<br>`你要握着它。`<br>`我们做的是一个会上班的。` | 建立对立面，一句话完成定位 |
| **11–16s** | 时间跳到 00:00 | `00:00 她自己醒了。` | 进入「一天」的叙事框架 |
| **16–34s** | **她的一天，四格快剪**（每格 4–5 秒，节奏对齐鼓点）<br>① 收信：邮件列表滚动，工程文档落进 `knowledge/`<br>② 看推荐：五个来源的候选刷过，打分数字跳动<br>③ 看视频：抽帧九宫格 + 音轨波形同时出现<br>④ 写日记：文字逐行落下 | `收信` / `挑片` / `看片` / `记下来` | **这一段是证据段**。每个动作都给真实数字，不摆姿势 |
| **34–44s** | 停在③的放大：画面里出现两条互相对不上的线索（一条字幕、一条音轨），被标红 | `她发现：画面和声音对不上。`<br>`这条视频没人提过。` | 展示「真看」而不是「走流程」，这是最难伪造的能力 |
| **44–56s** | 一条评论被发出 → 状态灯从绿变灰 → 弹出 `state=17` → 又变回绿（重发） | `发出去的评论，别人看不见。`<br>`B 站有个系统会静默吞掉它。`<br>`她自己去查。` | **这是全片最值钱的 12 秒**。别人不会讲自己的失败，讲失败才显得是真的 |
| **56–66s** | 分轮做视频：项目目录树 → `brief.md` → 代码一行行长出来 → `progress.md` 记第 1 轮 / 第 2 轮 | `一条片子做不完，她记下进度，明天接着来。` | 把「交付级」过程化，而不是吹结果 |
| **66–75s** | 黑底，只留一行仓库地址 + 她的名字 | `github.com/yht-cdd/bili-anthropos`<br>`Anthropos · 一个自己运营 B 站的 AI` | 收得干净，不喊口号 |

## 三、视觉系统（写死，不留发挥空间）

**形象**：沿用已定的 **DeepSeek 大肥鱼二创（鲸鱼娘）**，README 里已经这么写了，仓库也有贴纸。
不新造形象 —— 造一个新形象等于把已有的认知清零。

形象只在 **16–34s 那段** 出现（每格右下角小尺寸，不抢画面），其余段落一律是**界面和数据**。
理由：这片子的说服力来自「真实运行痕迹」，不来自角色卖萌。

**配色**（全部十六进制，写死）：

| 用途 | 色值 |
|---|---|
| 底色 | `#07080C` |
| 主文字 | `#EDEFF5` |
| 次文字 | `#8A90A2` |
| 强调（成功/在线） | `#4BE3A2` |
| 警示（失败/被吞） | `#FF5D5D` |
| 鲸蓝（形象、数据流） | `#5BA8FF` |
| 分隔线 | `#1A1D26` |

**排版**：
- 中文 `Noto Sans CJK SC`，字重 700 / 900
- 代码与数字 `JetBrains Mono`
- 主标题 `clamp(64px, 9vw, 104px)`，行高 1.12
- 副标题 40px，字距 0.02em
- 代码块 28px，行高 1.6

**动效规范**（对标 `.agents/示范/animations/` 里的 66 个范例）：
- 文字入场：`translateY(24px) → 0` + `opacity 0 → 1`，**20 帧**，`cubic-bezier(0.16,1,0.3,1)`
- 场景切换：**不做纯淡入淡出**，一律「上一场景上移 + 下一场景从下压入」，重叠 **15 帧**
- 数字跳动：等宽字体 + `tabular-nums`，避免宽度抖动
- 打字机效果：参考 `13-精准揭示`，用 `clipPath` 遮罩，不用逐字 DOM
- 数据流背景：参考 `15-数据流`，JS 生成，透明度 0.06，不做全屏抢戏

## 四、技术方案

```
videoproj/promo-1031/
├─ brief.md            这份计划扩写成的完整规格（约 800–1200 行）
├─ src/
│  ├─ index.ts         registerRoot
│  ├─ Root.tsx         <Composition id="AnthroposVideo" 2250 帧 1080×1920 30fps>
│  ├─ theme.ts         配色/字号/动效常数，全片唯一来源
│  ├─ components/      Terminal / Cursor / CodeLine / StatNumber / WhaleMark
│  └─ scenes/          S1Open / S2Contrast / S3Day / S4Mismatch / S5Avalon / S6Rounds / S7End
├─ audio/
│  ├─ bgm.mp3          免版税，或纯合成（sfx.mjs）
│  └─ cues.json        音效时间点（对齐上面分镜表）
└─ progress.md         每轮记一次，断点续做靠它
```

**渲染**：`render-video.mjs --project promo-1031`（链路已验证，能出片）
**但按你的要求：这轮只到「代码写完 + 本地类型检查通过」，不触发渲染。**

**音频**：先用 `sfx.mjs` 合成音效铺底（不花钱、时长精确）。配音用 TTS 单独存 `voice.mp3`，
最后合成时再叠 —— 这样即使配音不满意，片子也是完整的。
