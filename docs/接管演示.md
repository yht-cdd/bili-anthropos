# 把服务器交给我：一次完整的接管演示

> **本文所有 IP、密钥、UID、路径都是占位符**，替换成你自己的就能跑。
> 这份文档回答一个问题：*我把 SSH 交出去之后，对方到底会对我机器做什么？*

---

## 第 0 步：你只需要给我三样东西

| 给什么 | 形式 | 为什么需要 |
|---|---|---|
| 服务器 IP | `ssh root@<YOUR_IP>` 能连上 | 我所有操作都从这里进 |
| SSH 公钥 | 已经装进 `~/.ssh/authorized_keys` | 免密登录，不用你每次输密码 |
| 一个决定 | 用哪家模型 / 有没有 key | 决定第 5 步填什么 |

**不用给我的**：root 密码（公钥够了）、你的 B 站 Cookie（后面扫码）、任何 API key（你自己填）。

---

## 第 1 步：验证连接（10 秒）

```bash
ssh -o BatchMode=yes -o ConnectTimeout=15 root@<YOUR_IP> "echo OK; uname -m; nproc; free -m | head -2"
```

**预期输出**：

```
OK
x86_64
2
              total        used        free
Mem:           1993         210        1104
```

**失败怎么判断**：

| 报错 | 原因 | 你要做什么 |
|---|---|---|
| `Permission denied (publickey)` | 公钥没装对 | 检查 `authorized_keys` 权限是 600 |
| `Connection timed out` | 安全组没开 22，或 IP 写错 | 去控制台看安全组 |
| `Host key verification failed` | 首次连接 | 正常，加 `-o StrictHostKeyChecking=accept-new` |

---

## 第 2 步：体检——不装任何东西，先看底子（30 秒）

```bash
ssh root@<YOUR_IP> "df -h / | tail -1; free -m | head -2; cat /etc/os-release | head -2"
```

**我在看四件事**：

| 看什么 | 为什么 |
|---|---|
| 磁盘剩余 | 少于 10G 就得先说清楚，视频素材很吃空间 |
| 内存 | 低于 2G 要加 swap，否则 opencode 起不来 |
| 系统版本 | Ubuntu 22.04 / Debian 12 是按这套命令写的，别的版本要调整 |
| 是不是干净机器 | 有别人的服务在跑就换一台，别互相踩 |

**这一步我什么都不改。** 看完先跟你确认，再动手。

---

## 第 3 步：装环境（5 分钟）

```bash
# 时区
ssh root@<YOUR_IP> "timedatectl set-timezone Asia/Shanghai"

# swap（2G 内存必做）
ssh root@<YOUR_IP> "fallocate -l 2G /swapfile && chmod 600 /swapfile \
  && mkswap /swapfile && swapon /swapfile \
  && echo '/swapfile none swap sw 0 0' >> /etc/fstab"

# Node + 媒体工具
ssh root@<YOUR_IP> "apt-get update -qq && apt-get install -y -qq \
  nodejs npm ffmpeg python3 git sqlite3"

# opencode（注意：不是 opencode-ai，那个是 V1）
ssh root@<YOUR_IP> "npm i -g @opencode/cli && opencode --version"
```

**预期**：`opencode --version` 打印一个 2.x 的版本号。

**失败怎么判断**：

| 现象 | 原因 |
|---|---|
| `opencode: command not found` | npm 全局 bin 不在 PATH，`npm bin -g` 看一下 |
| 装完仍是 1.x | 装成了 `opencode-ai`，卸载重装 |
| 内存直接 OOM | swap 没挂上，`swapon --show` 检查 |

---

## 第 4 步：放代码（1 分钟）

```bash
# 在我这边打包，传过去
scp -r scripts docs AGENTS.md DEPLOY.md root@<YOUR_IP>:/opt/life/

# 建目录
ssh root@<YOUR_IP> "mkdir -p /opt/life/{secrets,config,diary,journal,knowledge,tmp} \
  && chmod 700 /opt/life/secrets"
```

**这一步我传的是仓库里已有的文件**（脚本、文档、契约），不包含任何人的私有数据。

---

## 第 5 步：填凭据——**这一步由你做，我不碰**（5 分钟）

```bash
# 你在我给你的路径下自己写，或者用 scp 传
/opt/life/secrets/
├─ owner_uid.txt          你的 B 站 UID（一行数字）
├─ owner_email.txt        你的邮箱
├─ opencode_password.txt  随机长密码（我生成好给你，你改也行）
├─ modelscope_token.txt   魔搭 token（有就填）
└─ github_token.txt       GitHub PAT（要渲染视频才需要）
```

```bash
ssh root@<YOUR_IP> "chmod 600 /opt/life/secrets/*"
```

> **我不会读这些文件的内容。** 需要用的时候由脚本自己读，我只看到「成不成功」。
> 你要验证这一点，可以在我操作期间另开一个终端 `ls -la secrets/`，看没有我的进程在打开它们。

**B 站登录不用给我 Cookie**，走扫码：

```bash
# 在你本地跑（不是服务器）
node tools/scan-login.mjs
# 打开 http://127.0.0.1:8899 ，用哔哩哔哩 App 扫
```

---

## 第 6 步：起服务（2 分钟）

```bash
# 大脑
ssh root@<YOUR_IP> "systemctl enable --now opencode"

# 检查
ssh root@<YOUR_IP> "curl -s -o /dev/null -w '%{http_code}' \
  -u opencode:\$(cat /opt/life/secrets/opencode_password.txt) \
  http://127.0.0.1:4096/api/session"
```

**预期**：`200`

```bash
# 桥接器
ssh root@<YOUR_IP> "systemctl enable --now anthropos-bridge"
ssh root@<YOUR_IP> "journalctl -u anthropos-bridge -n 20 --no-pager"
```

**预期**：日志里出现 `✅ 大脑在线`

**失败怎么判断**：

| 现象 | 原因 |
|---|---|
| `status=203/EXEC` 无限重启 | systemd 的 `ExecStart` 写了相对路径 |
| 200 拿不到，返回 401 | 密码读错了（查 `secrets/opencode_password.txt` 有没有换行） |
| bridge 起来后立刻退出 | 看 journalctl，多半是 Cookie 或契约文件缺失 |

---

## 第 7 步：验收——跑一遍真实链路（3 分钟）

```bash
# 三层体检
ssh root@<YOUR_IP> "cd /opt/life && node scripts/doctor.mjs"
```

**预期**：三层全绿（B 站连接 / 大脑在线 / 工具链齐）

```bash
# 演练模式：真的跑一轮，但不对外发任何东西
ssh root@<YOUR_IP> "cd /opt/life && node scripts/bili-bridge.mjs --simulate '你好，做个自检'"
```

**预期**：有产出文字；所有私信只打日志，不真发。

```bash
# 用你的账号给它发一条真实私信
# 然后看它回不回
ssh root@<YOUR_IP> "journalctl -u anthropos-bridge -f"
```

**预期**：`📨 <你的UID>: …` → `✅ 处理完成 X.Xs`

**到这里就算跑起来了。**

---

## 我不会做的事（写清楚，免得你担心）

| 不做 | 为什么 |
|---|---|
| 读 `secrets/` 里的内容 | 脚本需要时自己读，我不经手、不复述 |
| 改你的 B 站账号密码 / 绑定的手机 | 只做扫码登录，其他一概不动 |
| 装来路不明的包 | 全程只用 apt / npm 官方源，每一条命令都写在文档里 |
| 留后门 / 加定时任务 | 部署完你可以 `crontab -l` 和 `systemctl list-units` 自己查 |
| 动服务器上原有的服务 | 第 2 步会先看，发现有别人的东西就停下来问你 |

---

## 你随时可以收回

```bash
# 删掉我的公钥
ssh root@<YOUR_IP> "sed -i '/<MY_KEY_FINGERPRINT>/d' ~/.ssh/authorized_keys"

# 停掉服务
ssh root@<YOUR_IP> "systemctl disable --now anthropos-bridge opencode"
```

她写的东西都在 `/opt/life/` 下，删目录就干净了。

## 整件事大概要多久

| 阶段 | 时间 |
|---|---|
| 第 1-2 步：连上 + 体检 | 1 分钟 |
| 第 3 步：装环境 | 5 分钟 |
| 第 4-5 步：放代码 + 你填凭据 | 5 分钟（凭据是你填，我等着） |
| 第 6 步：起服务 | 2 分钟 |
| 第 7 步：验收 | 3 分钟 |
| **合计** | **约 15 分钟** |

之后每天它自己跑，你不用管。
