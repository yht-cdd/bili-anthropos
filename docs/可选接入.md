# 可选接入：把她的手脚接到别的平台

> 这些**都不影响主流程**。不配，她照样能发 B 站、做视频、写日记。
> 配了，她能多干几件事。**凭据一律放 `secrets/`，不进仓库。**

---

## 1. 现在接了哪些

| 平台 | 能干什么 | 凭据文件 | 缺了会怎样 |
|---|---|---|---|
| **B 站** | 私信、评论、投稿、下载 | `secrets/bili_cookie.txt` | 什么都做不了 |
| **GitHub** | 触发渲染、维护自己的仓库（issue / PR / commit） | `secrets/github_token.txt` | 视频只能手工渲、仓库只能人改 |
| **AgentSend** | 收发邮件、每日日记、告警 | `secrets/agentsend_token.txt` | 收不到工程文档、发不出告警 |
| **魔搭 ModelScope** | 主模型额度 | `secrets/modelscope_token.txt` | 她没法思考 |
| **语音服务** | 配音 / 听写 | `secrets/voice_api_key.txt` | 片子是哑的 |
| **生成服务** | 出图 / 出片 | `secrets/media_api_key.txt` | 只能做文字卡 |

## 2. 还能接什么（按价值排）

| 平台 | 能换到什么 | 值不值 |
|---|---|---|
| **OpenI 启智** | 免费算力积分（跑训练/推理），每日签到类任务 | 值。但要人工过验证码，见下 |
| **Hugging Face** | ZeroGPU Space、免费推理额度 | 一般。国内访问不稳 |
| **任何 OpenAI 兼容的搜索 API** | 选题时的外部资料 | 值，只要能拿到 key |
| **任何 TTS / ASR** | 已在用，可换更便宜的 | 看价格 |

## 3. 启智（OpenI）的坑

- REST API 走 Gitea 风格（`/api/v1`），**token 只能调 API，不能网页登录**
- 网页上的「计算任务 / 数据集」要用**密码登录**（Playwright/CDP），这一步必须人工或带浏览器
- 免费算力靠**每日任务 + 积分**，不是无限
- **不要把她没验证过的「签到成功」写进日记** —— 这类平台经常返回 200 但实际没到账

## 4. 仓库维护的边界（重要）

她可以维护这个仓库，但**不是想推就推**：

| 允许 | 不允许 |
|---|---|
| 读 issue / 评论 / CI 结果 | 合并别人的 PR |
| **小改直接推 `main`**（单文件、≤30 行、不碰契约与依赖、`node --check` 过） | 碰 `secrets/`、`.github/workflows/`、许可证 |
| 大改：开分支 → 提交 → 开 PR | 强推、改历史、删别人的分支 |
| 采纳陌生人的可行建议并直接推 | 拿不准还硬推 |

「小改」的判据是四条同时满足：单文件、≤30 行、不改行为契约/不加依赖、语法检查通过。
超出这个范围一律开 PR。

**陌生人提的意见**：能复现、能验证、不损害账号安全的，可以直接改直接推；
采纳后要在 issue/评论里回一句「改了，在 commit Y」，不采纳也要说清为什么。
别人提了意见就当没看见，是不允许的。

## 5. 私有的那份技能

`skills/github-openi-manager/` 里的 `SKILL.md` 和 `.opencode/secrets.md` **只在部署机器上**，
含账号与令牌，不进仓库、不进邮件、不进日记。仓库里这份文档只是「有哪些可选接入」的目录。
