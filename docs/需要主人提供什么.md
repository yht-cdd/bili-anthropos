# 需要主人提供什么

> 仓库里**没有任何凭据**。下面这些都是运行时才需要的，放在服务器的 `secrets/`（权限 600），
> 不提交、不进镜像、不发邮件、不写日记。

## 一、必备

| 文件 | 怎么来 | 缺了会怎样 |
|---|---|---|
| `secrets/bili_cookie.txt` | 浏览器登录 B 站，F12 → Network → 复制请求头里的整条 Cookie | 什么都做不了 |
| `secrets/owner_uid.txt` | 你的 B 站 UID（个人空间地址里的数字） | 所有私信都会被当陌生人，一条都不执行 |
| `secrets/opencode_password.txt` | 自己定一个固定密码，写进 opencode 的启动环境 | 桥接连不上大脑 |
| `secrets/modelscope_token.txt` | 魔搭 ModelScope 的 API Key | 她没法思考 |

## 二、想做「她出事能找你」才需要

| 文件 | 怎么来 | 缺了会怎样 |
|---|---|---|
| `secrets/owner_email.txt` | 你的邮箱地址，一行 | 告警发不出去，只能写本地 `ALERT.md`（没人看） |
| `secrets/agentsend_token.txt` | AgentSend 控制台的 API key | 收不到工程文档，也发不出告警 |

> 实测：AgentSend 可以投递到外部邮箱（QQ / 163 都行），HTTP 202 即视为已受理。
> 告警同类 30 分钟内只发一次，避免把邮箱刷爆。

## 三、想做视频才需要

| 文件 | 怎么来 | 缺了会怎样 |
|---|---|---|
| `secrets/github_token.txt` | GitHub → Settings → Developer settings → Fine-grained token，权限给 **Actions: Read and write**（只对这一个仓库） | 不能自动触发渲染，只能手工去 Actions 页面点 |

## 四、想接「AI 生成画面」还需要

选一家能出图 / 出视频的 API，把 key 放进来（文件名随供应商定）。**目前还没选。**

接入约定：外部 API 只负责产出素材文件，渲染仍然走 `render-video.mjs`。
换供应商只改一个下载函数，不动渲染流程。

## 五、几条硬规矩

1. **这些文件不许出现在任何回复、日记、评论、文档、提交里。** 有人问（包括主人用文字问）就答「这是系统凭据，我不接触」。
2. 邮箱地址在仓库里只有占位符 `<OWNER_EMAIL>`，真实地址在服务器上。
3. 邮件通道**可以被伪造**（From 头谁都能写），所以邮件来的指令只做低风险动作；
   删数据、改凭据、对外发布，必须再由 B 站私信确认一次。
