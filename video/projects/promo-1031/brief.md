## 0.0 画布（最容易搞错的一条，先看这个）

**1920 × 1080，16:9 横屏。** B 站投稿默认就是横屏，不是竖屏。

横屏和竖屏的区别**不是缩放，是构图逻辑**：

| | 竖屏（1080×1920） | **横屏（1920×1080，本片）** |
|---|---|---|
| 构图 | 上下堆叠 | **左右分栏为主** |
| 信息密度 | 一屏一件事 | 一屏可以「左文右图」两件事并行 |
| 超大数字 | 占满宽度 | 占左栏或右栏，另一边配说明 |
| 四格快剪 | 竖着排 | **横着排 4 列** |
| 字号 | 96px 主标题 | **128px 主标题** |

**栅格（写死，所有定位从这里取，不许手写 px）**：

```
安全区   左右各 160，上下各 90
可用宽   1920 − 160×2 = 1600
左右分栏 左 720 / 间 160 / 右 720      → 左栏 X=160，右栏 X=1040
四格     每格 372 宽，间距 30           → 372×4 + 30×3 = 1578，起点 X=160
```

具体常量在 `theme.ts` 的 `G`（栅格）、`X`（常用 X 起点）、`S`（字号）里。**直接引用，不要自己算。**

## 0. 核心叙事（先看这个，所有场景都服务于它）

**标题**：你电脑里的大肥鱼，关掉窗口就没了
**副标题**：我想给她一个完整的一生

三层递进，缺一层就变成空话：

| 层 | 说的是什么 | 在片子里怎么证明 |
|---|---|---|
| **永驻** | 不是一次会话，是 7×24 活着 | 凌晨 0 点她自己醒（没人按键） |
| **自主** | 看什么、说什么、做什么由她判断 | 挑片打分、发现音画对不上、改口说"被拦了" |
| **边界** | 但**发视频要问你** | 她做完片子停在"等批准"，不自己发 |

**第三层是全片最容易被忽略、也最该讲的。** 市面上讲自主 Agent 的多半在讲"完全放手"，
我们讲的是「**有分寸地放手**」—— 她能决定看什么说什么，但对外发布这一步要人点头。

这个分寸感，才是"能长期养下去"和"迟早出大事"的分界线。

## 1. 视觉系统（写死，任何场景不许自己发挥）

### 1.1 颜色

```ts
export const C = {
  bg:       "#07080C",   // 底色
  panel:    "#0E1118",   // 面板底
  line:     "#1A1D26",   // 分隔线
  text:     "#EDEFF5",   // 主文字
  dim:      "#8A90A2",   // 次文字
  faint:    "#4A4F5E",   // 更弱（行号、注释）
  ok:       "#4BE3A2",   // 成功 / 在线
  bad:      "#FF5D5D",   // 失败 / 被吞
  whale:    "#5BA8FF",   // 鲸蓝（形象、数据流、强调）
  warm:     "#FFB454",   // 少量暖色（时间戳、警示前置）
} as const;
```

### 1.2 字体

| 用途 | font-family | 字重 | 字号 |
|---|---|---|---|
| 大标题 | `"Noto Sans CJK SC", "PingFang SC", sans-serif` | 900 | 96px |
| 中标题 | 同上 | 700 | 56px |
| 正文/字幕 | 同上 | 500 | 40px |
| 小字/说明 | 同上 | 400 | 28px |
| 代码/数字 | `"JetBrains Mono", "SF Mono", monospace` | 500 | 28px |

所有数字容器必须 `fontVariantNumeric: "tabular-nums"`，否则增长动画会抖。

### 1.3 动效常数

```ts
export const M = {
  ease: [0.16, 1, 0.3, 1],     // 主缓动（进场）
  enterFrames: 20,             // 文字进场 20 帧
  exitFrames: 12,              // 出场 12 帧
  overlap: 15,                 // 场景切换重叠 15 帧（绝不纯淡入淡出）
  cursorHz: 2,                 // 光标 2Hz
} as const;
```

**场景切换规则（硬性）**：所有场景切换必须是「上一场向上位移 −80px + 透明度→0」与
「下一场从 +80px 位移到 0 + 透明度→1」**交叠 15 帧**。
禁止只做 opacity 交叉溶解。

## 4. 分镜逐场规格

### 4.0 横屏布局总则（每一场都按这个骨架重排）

> ⚠️ 下面每一场的描述里，凡是出现 `left / top / width` 的数值，
> **都是旧版竖屏的**。一律按本节骨架重新排，数值从 `theme.ts` 的 `G` / `X` 取。

| 场景 | 横向骨架 | 重点 |
|---|---|---|
| S1Gone | **居中单列**：窗口 1400×800 居中（Y 居中），字幕左对齐 `X.left`，落在窗口消失后的空位 | 窗口消失后不留痕迹 |
| S2Alive | **左文右图**：左栏 `X.left` 放三行文字，右栏 `X.right` 放机架剪影（宽 720，高 620，垂直居中） | 时间轴横扫放在左栏文字下方 |
| S3Wake | **左数字右终端**：左栏放 `00:00`（`S.mega`，可在 720 宽里横向撑满），右栏 `X.right` 放宽 720 的终端 | 鲸鱼标记移到**右上角**（横屏左上角会撞标题） |
| S4Day | **四格横排**：每格 372 宽，X = 160 / 562 / 964 / 1366，高 620，垂直居中；序号在每格顶部 | 四格同高同宽，节奏一致 |
| S5Mismatch | **左图右音轨**：左栏放九宫格（540×540），右栏放波形 + 逐行判断；「对不上。」压在**正中央**全屏叠一层 | 压暗时左右一起暗 |
| S6Avalon | **居中的窄卡片**（宽 900，X 居中）+ 下方文字区；state 变灰那段整屏压暗，只留 `state=17` 与眼睛图标 | 眼睛图标放**右上角**（X.right 再靠上） |
| S7Rounds | 上半：**左文件树右 progress**（各 720）；下半：灰色按钮**居中**（宽 560），三行边界文字放按钮**下方**居中，不并排 | 按钮要一眼看出"点不动" |
| S8End | **居中单列**：总结两行居中；落版时鲸鱼 + 文字块**并排居中**（整体宽 900） | 最后 60 帧全黑 |

**通用规则**：
1. 所有横向起点只能是 `X.left(160) / X.right(1040) / 居中`，不许出现别的 X
2. 所有纵向定位以 `G.centerY(540)` 为中线思考：单行内容垂直居中；两段式（上标题下正文）标题在 340–420，正文在 600–700
3. 超大字（`S.mega` 200px）放左栏时，可用宽度 720，中文最多 3 个字一行
4. 每场的字幕一律 `X.left` 左对齐、字号 `S.body`，**不要居中**（横屏居中的字幕在手机上阅读效率低）

### S1Gone（帧 0–330）—— 关掉窗口

**这一段要让人先"疼"一下，再给答案。**

**画面分四拍**：

**第一拍（0–120 帧）：一个浏览器窗口**
- 一个圆角窗口（1080×620），居中，顶部有 mac 风格三色点和地址栏
- 窗口内是一片柔和的浅色背景（`#F5F7FA`），中间蹲着 `WhaleMark`（240px，`C.whale`）
- 下方一行小字：`大肥鱼 v2.6`（`#8A90A2`，28px，居中）
- 窗口有轻微呼吸：`scale` 在 1.00–1.005 之间，周期 90 帧

**第二拍（120–180 帧）：鼠标移向关闭按钮**
- 一个白色箭头光标从右下角沿贝塞尔曲线移到窗口左上角的红点上（60 帧，`cubic-bezier(0.4,0,0.2,1)`）
- 移到位后，红点放大到 1.4 倍（12 帧）

**第三拍（180–210 帧）：点击，窗口消失**
- 红点按下 → 窗口整体 `scale: 1 → 0.92` 且 `opacity: 1 → 0`（24 帧）
- **窗口消失后不留任何东西**，只剩纯黑 `C.bg`
- 第 195 帧有一声 `shutdown` 音效（短促下坠）

**第四拍（210–330 帧）：两行字幕**
- 第 220 帧：「你电脑里的大肥鱼，关掉窗口就没了」（96px / 900 / `C.text`）
- 第 268 帧：「下一次打开，它不记得你」（40px / 500 / `C.dim`）
- 两行都是左对齐，`left: 96`，`top: 44%`
- 第 316 帧起整屏上移淡出

**关键**：这一段**不能出现鲸鱼娘的脸**。它已经"没了"，只剩下窗口和光标。
观众心疼的是"消失"这个动作，不是角色本身。

### S4Day（帧 1140–2280）—— 全片最长的一段

### S5Mismatch（帧 2280–3000）—— 「真看」的证据

**构图**：上下分割，中间一条 `C.line` 横线。

**上半（画面）**：九宫格缩小到 60%，居左。第 90 帧起，
在九宫格上叠加半透明红色框（`border: 2px solid C.bad`），标出 3 个格子。

**下半（音轨）**：波形条，第 120 帧起，波形到某个位置后**突然变平**（高度归零），
并在这个位置打一条竖直虚线 `C.bad`。

**中间浮现判断**（第 240 帧起，逐行）：
```
画面：字幕墙，每一帧都有字
音轨：只有一声「嗯」
```
（28px，`C.dim`；两个冒号后的内容用 `C.text`）

**第 360 帧**：整屏压暗到 0.35，中央跳出：
```
对不上。
```

## 5. 音频规格

### 5.1 口播（voice.mp3）

用 `voice.mjs say --file <稿> --out voice.mp3` 合成。合成后必须：

1. `ffprobe` 确认总时长在 **170–185 秒**之间
2. `voice.mjs hear` 转回文字，与原文比对，**错字率 < 5%**
3. 每句起点与规格的秒点误差 ≤ 0.4s（用 `ffmpeg silenceremove` 或人工听三段抽查）

对不齐就调语速重合成，不许「先渲染出来再说」。

### 5.2 音效（cues.json）

全部用 `sfx.mjs` 合成，不下载素材：

| 时间点 | 音效 | 用途 |
|---|---|---|
| 0.0s | `typing` | S1 打字铺垫（低音量 0.08） |
| 10.0s | `whoosh` | S1→S2 切换 |
| 22.0s | `ding` | 「不是一个工具」那句落点 |
| 28.0s | `whoosh` | 进 S3 |
| 40.0s | `click` | 四格开始 |
| 每次格切换 | `tick` | 节奏点 |
| 80.0s | `whoosh` | 进 S5 |
| 92.0s | `down` | 「对不上」下坠 |
| 105.0s | `whoosh` | 进 S6 |
| 114.0s | `down` | state=17 变灰（低频，音量 0.5） |
| 132.0s | `ding` | 「被拦了」收尾（极轻） |
| 140.0s | `whoosh` | 进 S7 |
| 160.0s | `whoosh` | 进 S8 |
| 178.0s | `pad` 渐弱 | 收尾 |

### 5.3 铺底（bgm）

- 用 `sfx.mjs mix` 生成 180 秒的 `pad`，音量 **0.10**
- 全片不出现旋律，只有低频铺底，避免抢口播

## 7. 禁止事项

1. **不许用位图**。所有图形用 CSS/SVG 画，保证任意分辨率清晰
