## R1 · 2026-11-09 23:15 · 脚手架 + 五段场景 + 定帧自验（本轮）

### 做了什么

1. **脚手架**：只从 letter-1107 拷 `tsconfig.json` + `src/anim.ts` + `src/utils.ts`（mulberry32），
   `node_modules` 用软链（730MB 不复制），其余 src 全部新写，**没有 import letter-1107 的任何源文件**。
2. **时长/规格**：1920×1080@30fps，2472 帧 = 82.4s（口播 80.376s + 末尾 2s 黑场）。
   composition `Preview1109`，不内嵌音轨，最后用 ffmpeg mux `audio/voice-full.mp3`。
3. **场景时间轴不是按 brief 的 443 字比例硬算的**，而是用 `ffmpeg silencedetect`（-25dB/0.15s）
   取到 48 个静音段，按「语速均匀 + 句末停顿长于逗号」做 DP 对齐，得到 22 行口播的真实起止
   （见 src/data/preview.ts 的 `from`）。实测行首误差 <0.35s，S-A 结束落在 7.71s 而不是 brief 估的 ~13s
   —— 443 字与 `tmp/preview-voice.txt` 实际的 406 字（含标点）对不上，按真实音频走。
4. **五段**：
   - S-A 私信气泡：打字机 2 帧/字、光标 16 帧闪、发送者只写「主人」。
   - S-B 鱼墙 2s → 数据卡（RGB 三分离 8 帧 + 10px 错位），两条样例评论 + 一排同色头像。
   - S-C 稿件卡 + 灰卡「稿件已转为仅自己可见」+ 红印章（rot -8°，scale 1.4→1，12 帧）+ 两根对比条
     （27.9/1.9、29.2/1.7，条长=百分比×1400，数字随条增长）。
   - S-D 三组字：第一「我是 AI」→ 第二三不 + 金黄「token 是成本，不是人质」→ 第三「不点名」→ 鱼无罪。
   - S-E 红字题眼 RGB 偏移 8 帧砸入 + 小字 + 2408 起淡黑，2412 后全黑。
5. **PiP**：`<Loop durationInFrames={155}>` + `OffthreadVideo trimBefore={90}`。
   原片 10.72s 首尾帧差 MAE 7.5（闭嘴→睁眼），整段 loop 会跳；实测第 90 与 245 帧几乎同帧
   （160×90 灰度 MAE 0.15），取 5.17s 无缝环。定帧 154/155 边界实测 MAE 0.46（其余区域 0.03）。
   全片常驻；S-D 放大 1.35；S-E 画面全黑后改为右上角 150px 指纹窗（同素材、同环），避免黑场里挂一个白圈。
6. **红线**：无 UID/昵称（气泡只写「主人」）；鱼墙 30 条是句式模式重写的合成样例，不含任何真实账号；
   文本全在 `src/data/preview.ts`；无 Math.random / Date.now / CSS 动画 / 新依赖。
