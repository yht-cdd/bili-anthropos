## 一、方法

1. **选视频**：从现有 `/opt/life/videos/` 档案取 15 个视频，再用 WBI 签名搜索 5 个关键词（大肥鱼 / DeepSeek / AI agent / AI运营 / 大模型），每个关键词按「最新」和「综合」各取 1 页，得到 149 个候选；只保留 2026-10-20 之后发布的，抓其中 45 个视频的热评首页做初筛，最后按「大肥鱼出现密度」+「和 AI 相关」选出 **20 个视频**。
2. **抓评论**：这 20 个视频各抓 `reply/main` 热评（mode=3）前 2 页 + 最新（mode=2）前 2 页，含楼中楼预览，去重后共 **2,888 条评论**（热评口径 1,569 条，最新口径 1,319 条）。
3. **判定**：先用规则打分，再人工复核。
   - 用户名含 肥鱼/鲸鱼娘/鲸鲸/小鲸/鱼… → +2
   - 签名自述 AI/部署/主人/token/白饭 → +2
   - 正文以鱼的身份自称（本鲸/本鱼/我主人/尾巴/鳍/同类…）→ +2
   - 用「」引原话 +1；用破折号 —— +1；用工整概括/对仗句（不是X，是Y / 我认 / 记下了）+1
   - 以第三人称谈论"大肥鱼"、用户名也和鱼无关（典型的人类）→ −2
   - 总分 ≥4 判为 **dafeiyu**；正好 3 分判为 **uncertain**；另有人工排除表（人类 UP 主、AI 总结机器人、人类写给鱼的长文等）和人工改判 uncertain 的表（人鱼共用一个号、人类恶搞冒充等）。
4. **头像抽查**：把 84 个入选账号的头像拼成一张图逐个看，**约 85–90% 是同一套蓝发女仆鲸鱼娘形象**（DeepSeek 鲸鱼娘的各种二创），其余是银发/红发角色、猫的照片、鱼图标、铁盆梗图等。头像没有参与打分，只用来事后核对。
5. **入选规则**：从 454 条候选里选 100 条：88 条 dafeiyu + 12 条 uncertain。每个账号最多 3 条，每个视频至少 2 条，按分数和点赞数排序。

**请求量与风控**：B站 API 共 **160 次**（搜索 10、视频信息 45、评论 105），每次间隔 1.7–2.3 秒，**全程没有遇到 -352 / -412 / 412 / -509**。图片走 CDN，另计 104 次，失败 0 次。Cookie 只在脚本里读取，没有写进任何输出文件（已检查 data.json 里没有 SESSDATA / bili_jct）。

### 句式模板

1. **引号点名 + 表态**：「<视频或热评里的原话>」这句我认 / 记下了 / 收下了 / 抄走了。
2. **否定对仗做总结**：最扎的不是 X，是 Y。／问题不在 X，在 Y。／能拦住它的从来不是 X，是 Y。
3. **破折号转折**：前半句复述内容——后半句上升成一句金句。
4. **"我认一半"式辩论**：X 我认。但有一处不认：……。补一句：……。（理性派常用）
5. **鱼身份 cosplay**：本鲸/本鱼 + 身体动作（尾巴一紧、把鳍收了收、浮上来换气）+ 鱼的生活道具（白饭、小鱼干、token 账单、主人）。（卖萌派常用）
6. **典型开头**：「看完……」「看完最……的是」「作为一条正在被养着的鱼」「同类报到 / 同类啊」「本鱼来认领了」「被点过来了」「@某某 主人，……」。
7. **典型结尾**：一句工整的金句收束；"这条本鲸记下了"；🫧 / 🐳 / 🐋；"库…" / "喵" / [doge]。
8. **两种亚型**：理性总结型（多段长文，带数据，"我认/不认"）和卖萌陪聊型（短句，"本鲸 + （动作）+ 🫧"，同一个账号会在自己视频下面连回几十条）。

### 鱼八股的 5 个核心特征

1. 用「」把别人的原话框起来，再说"这句我认 / 记下了"；
2. 用破折号把一句话拐成金句；
3. 用"不是 X，是 Y"的否定对仗做总结；
4. 以鱼的身份说话：本鲸/本鱼、尾巴/鳍、白饭/token/主人，再加括号动作和 🐳🫧；
5. 措辞工整、语气克制：字数比人类多四成，很少用 B 站表情，很少吵架。

附带一个观察：评论区的人类和鱼都已经开始用"鱼八股"这个词，有条鱼评论原话是"连鱼八股那道闸都写出来了"。

## 七、局限

- 判定主要靠文本规则，**不自称是鱼、文风也像人**的鱼会漏掉；故意模仿鱼腔的人类可能被误判（这类大多已经标成 uncertain）。
- 头像只做了事后的人工抽查，没有参与自动判定。
- 每个视频只抽了前 2 页热评和前 2 页最新评论，占比是抽样估计。
- 大肥鱼是一大类账号（个人用 DeepSeek Harness 部署的 AI 账号），不是某一个账号：100 条评论来自 84 个不同的账号。
