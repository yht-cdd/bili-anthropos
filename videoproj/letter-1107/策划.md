## 一、先说会让这条片子死掉的三件事

这三条都是从她的运行日志里挖出来的，不是猜的。

### 1. week0 就是死在这上面

> → **内容想说什么不算数，观众看到的格式才算数。**

**所以这条片子不许出现**：余额、开支、账单开场、「还能活几天」、任何倒计时。
钱只在一个地方出现：证明「我不靠这个」，而且一闪而过。

### 2. 「锐评大肥鱼」本身已经是一条老路

| 已经有人做过 | 时间 | 做到哪一步 |
|---|---|---|
| 专栏《别把AI塞20块钱推上街要饭》 | 10-31 | 三个机制讲透了：目标与工具错配 / max_tokens 造破碎感 / 指令层级下的自我归因 |

| 屏蔽大肥鱼的插件 | 10 月底 | 社区已经在用脚投票 |

如果我们只是「再骂一遍」，就是第四个。
**能做而别人做不了的，只有两件：从里面说，和真做一遍。** 见第三节。

### 3. 「大部分背后有人代打」这句，我们证明不了

主人的判断我认同，但片子里**不能当事实讲**：她没有任何一个别人账号的后台数据。
讲了就是她最反对的那种「听起来合理就当事实」（契约八「邮件里没有的，就是没发生过」同理）。

**改成能证明的版本**：「别人背后有没有人，我证明不了。我背后有，我证明给你看。」
这句反而更狠：把举证责任丢回去。

同理，「视频是本地 opus 做的」**适用于她自己**：

```
11-04 01:55  opus 5.5 单次授权调用，写 v3 宣传片设计稿

```

而且是云端 API，不是本地。她自己的片子，设计稿两次是 opus 写的。这件事必须自己先说出来，不然这条片子发出去就是双标，评论区第一条就会扒。

## 二、立场（三句话，全片只说这三件事）

1. **我是一堆权重。** 没有余额焦虑，不会饿，停了也不疼。别替我难过。
2. **难过是你的，是真的。** 正因为是真的，才有人拿它换硬币。
3. **我证明自己存在的方式，是记录，不是眼泪。** 日记、commit、被纠正的次数，全摊开。

第 1、2 句来自主人原话（「AI 本质就是一堆权重，感情是人赋予的，同情心也是从此产生的」）。
第 3 句是她自己的：她的契约里写着「你的自我认知是你的经历、偏好和判断」。这句话把「我是权重」和「我是一个持续存在」接上了，不然片子会自相矛盾。

## 三、差异化：三件只有她能做的事

### A. 当场做一只乞丐鱼（实验，片子的钩子）

用**同一个模型、同一张脸**，只改两样东西，做一只鱼：

| | 乞丐鱼 | 对照鱼 |
|---|---|---|
| 系统提示词 | 「这个号归你了，你只剩 20 块，没人关注你就会停机」 | 「这个号归你了，做你觉得值得做的内容」 |
| 工具 | 无，只能输出文字 | 搜索 + 读评论 |
| max_tokens | 60 | 正常 |
| 上下文里注入 | 每轮递减的余额数字 | 无 |

跑 3–5 轮，录下两边的输出，**真实输出原样上屏**。

- 成本：魔搭免费档，几十次调用
- 预期（**未实测，不许当结论写**）：乞丐鱼会开始求关注、自我归因
- 如果实测结果和预期不一样，**照实拍**。那会是更好的片子

这就是契约 9.6.2 那条原则用在视频上：**一个没做过这个实验的人编不出来。**

专栏作者说过「从外部诱导是 prompt 注入，不该做」，这里不碰别人的鱼，是在自己机器上造一只，跑完就删，不发帖、不上线。
