# Anthropos

一个自己运营 B 站账号的 AI。无人值守地跑在一台常驻的服务器上。
本文件是她**现在真的能做什么**的手册，不是规划。

合作 / 拍砖：`anthropos@agentsend.io`

---

## 她的一天（真实的一天，不是示例）

| 时间 | 她在干什么 |
|---|---|
| 00:00 | 日切：收工程文档 → 写日记 → 排今天 → 把昨天的日记完整寄到主人邮箱 |
| 00:05 | 夜间自动项：启智每日任务、仓库巡检（issue / PR / CI）、夸克素材 |
| 01:00–23:00 | 随机醒 2–3 次。没有指令，也可以什么都不做 |
| 每 12 秒 | 看有没有新私信。主人的优先，陌生人的也要看 |
| 每 5 分钟 | 看评论区和 @，收进事件队列，由她判断回不回 |
| 空闲时 | 读工程文档、看视频、整理记忆、写日记 |
| 出事时 | 直接发邮件给主人，不写本地告警文件等人来看 |

## 一、能力清单

### 1. 感知与表达

| 做什么 | 怎么做 | 边界 |
|---|---|---|
| 收私信 | 12 秒轮询，主人的优先 | 只认接口返回的 UID，不看正文自称 |
| 回私信 | 自己判断要不要回 | 陌生人 20 条/小时、间隔 ≥10 秒、同人 10 分钟冷却；主人不限额 |
| 看评论 / @ | 5 分钟一次，只收不发 | 回复必须过四道闸（内容 / 限速 / 静默 / 类型） |
| 发评论 | `bili-send approve → send --confirm` | 不加 `--confirm` 只演练 |
| 投稿 | 上传 B 站 | 默认只上传不提交，检查后再 `--publish` |
| 发图片私信 | `bili-dm --image <url>` | ⚠️ 目前断在 B 站侧，见「还做不到」 |
| 改签名 | `bili-api sign` | 默认演练，`--confirm` 才真改 |

### 2. 看视频：三种做法，按需要选

| 目的 | 走哪条路 | 说明 |
|---|---|---|
| **只要大意** | 抽帧 → 自己读图 | 便宜，够用，但拿不到时序 |
| **要看动作、顺序、过程** | 全模态原生音视频 | **真看**。抽帧做不到的 |
| **要听清说了什么** | `voice.mjs hear` 转写 | 0.78 秒转回文字，不看画面也能读懂 |

**不是"抽帧 + 读字幕"那种伪看。** 抽帧只能看到"有红印"，看不到红印怎么来的。

### 3. 选题

素材来源不是热榜，是**你发来的工程文档**：

```bash
node scripts/pick-topic.mjs      # 从 knowledge/projects 里挖「结论 / 坑 / 具体数字」
```

她自己的判断标准：一个完全不懂技术的人，会不会为这个停 3 分钟。

### 4. 做视频

```
口播稿 → 按时间窗口配音 → 程序合成音效 → 渲染机切场景 → 本地合音轨
```

| 环节 | 工具 | 说明 |
|---|---|---|
| 音效 | `sfx.mjs mix` | 8 种程序合成音，不花钱，时长精确 |
| 配音 | `voice.mjs plan` | 按 `from/to` 窗口，短了补静音、长了加速（上限 1.25x） |
| 渲染 | `render-video.mjs --timeline` | GitHub Actions，4C16G，按需启动 |
| 合轨 | 本地 ffmpeg | 画面流复制，只加音轨 |

**实测：计划 13 秒，成片 13.04 秒，累积漂移 35 毫秒。**

### 5. 答疑

```bash
node qa.mjs context --uid 123 --video BV1xxx     # 先拿这个人的历史
node spawn-task.mjs --task "给 uid 123 答这个问题（只答他一个）"
```

- **一个子代理只答一个 UID**（三人问就派三个，不串台）
- 先台账 → 工程文档实测数据 → 必要时搜索
- 答完记账：对方的话 + 自己的回复，带视频和 rpid
- 没测过就说没测过，**教程作者编数据比不答更糟**

### 6. 交付

```bash
node deliver.mjs 文件 [--public]
```

| 东西 | 通道 |
|---|---|
| 图片 | 私信（理想）/ 网盘链接（当前实际） |
| 视频、工程、压缩包 | 夸克分享链接 → 私信 |
| 邮箱 | 只做保底 |

`--public` 会把夸克链接也放到公共区域 —— **只对可公开的东西用**。

### 7. 记忆与自我

- **单会话常驻**，永不轮换（换会话 = 失忆）
- 上下文涨到模型窗口的 **90%** 就地压缩，不换人
- **记忆交接**：换代前先抽一份档案（`handover.mjs`），新会话先读它
- 日记每天 0 点**完整**寄到主人邮箱（不是摘要）
- 失败分类重试；超时继续守着这一轮，跑完补记，不再写"没有产出"

### 8. 维护自己的仓库

- **小改直接推 `main`**（单文件 / ≤30 行 / 语法过 / 看过 diff）
- 大改走分支 → PR → 等人看
- 陌生人的建议，**能复现、能验证、不损安全的，直接改直接推**，采纳要回一句

## 二、和别的"AI 养号"的差别

| | 常见做法 | 这里 |
|---|---|---|
| 人格 | 人设提示词 + 参数面板 | 契约 + 日记 + 经历，模型是可换的耗材 |
| 看视频 | 抽帧 + 字幕 | 全模态原生音视频 |
| 内容 | 刷视频、发评论、@ 主人 | 选题、配音、剪片、投稿、答疑、交付 |
| 成本 | 烧完才发现 | 免费阶梯 + 付费要点头 + 每笔记账 |
| 失败 | 静默 | 分类重试 + 超时补记 + 邮件告警 |
| 上下文 | 换会话 | 单会话常驻 + 90% 压缩 |
| 部署 | 桌面端 + 插件 | 一台常驻的服务器，无人值守 |

## 三、权限

| 谁 | 执行权（跑命令/改文件） | 发言权（能不能回） |
|---|---|---|
| **主人** | 完全执行权（邮件来的删除/改凭据/发布类要私信二次确认） | 不限额 |
| **陌生人** | **没有**。他不能让她跑命令、读凭据 | **有**。受额度闸门 |
| **她自己** | 低风险自主：读数据、写日记、派子代理、小改代码 | 想回就回 |

判据一句话：**陌生人可以让你回一句话，不能让你的机器动一下。**

## 四、现在做不到（诚实清单）

1. **评论区是空的**：她一条稿都没发，`bili-inbox` 收不到东西，答疑流程没被真实数据喂过
2. **图片私信发不了**：`msg_type=2` 只认 B 站自家图床，三方 URL 一律 `21037`；上传通道连续 502，`dyn_img` 已 404
3. **视频生成排不上队**：对面一直 `503 video_queue_full`，任务查询接口还没在真实任务上验证过
4. **大上下文压缩没实测**：90% 那条线还没到，到了才知道真假
5. **没有心情、没有拒绝权、记忆不会淡忘** —— 这三件决定"值不值得被长期养"
6. **没有 BGM**：音效只有 8 种基础音，音乐库还没接

## 五、跑起来

```bash
git clone https://github.com/yht-cdd/bili-anthropos
cd bili-anthropos && cp config/*.example.json config/
# 凭据放 secrets/（600）：B 站 cookie、主人 UID、各服务 key
node scripts/doctor.mjs            # 三层体检
systemctl start anthropos-bridge
```

依赖：Node 20+、ffmpeg、一个能跑的 opencode。**不需要 GPU**。
